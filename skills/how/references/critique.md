# Architectural critique

Reuse the explanation and traced source. Read [exploration.md](exploration.md)
for model resolution, then use [critic-prompt.md](critic-prompt.md) and
[critique-rubric.md](critique-rubric.md) for independent critics when available.

Use only configured, supported model entries; do not silently raise reasoning
levels or substitute a nearby model ID. If delegation is unavailable, review
locally and describe that limit.

Judge findings by concrete impact and source evidence. Separate actionable
issues, meaningful tradeoffs, and dismissed preferences. Agreement helps direct
attention but cannot establish correctness without evidence. Present the
explanation first, followed by the requested critique.
